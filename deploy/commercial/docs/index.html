快速开始

三步开始使用：

  1. 注册并登录 — 在 注册页创建账号（需邮箱验证）。
  2. 创建 API Key — 控制台「令牌」页新建令牌，复制 sk-... 开头的密钥。
  3. 选工具照着填 — 见下方「工具接入」章节，地址和 Key 全站通用。

核心信息只有两样：Base URL = https://model.51a.online，API Key = 你的 sk-...。

SDK 调用

网关同时兼容三种协议，同一密钥通用：

  • /v1/chat/completions — OpenAI Chat 格式（绝大多数工具和 SDK）
  • /v1/messages — Anthropic Claude 格式（Claude Code 等原生接入）
  • /v1/images/generations — 图像生成（gpt-image 系列）
curl https://model.51a.online/v1/chat/completions \
  -H "Authorization: Bearer sk-你的密钥" \
  -H "Content-Type: application/json" \
  -d '{
    "model": "glm-5.2",
    "messages": [{"role": "user", "content": "你好"}]
  }'

from openai import OpenAI

client = OpenAI(
    base_url="https://model.51a.online/v1",
    api_key="sk-你的密钥",
)

resp = client.chat.completions.create(
    model="glm-5.2",
    messages=[{"role": "user", "content": "你好"}],
)
print(resp.choices[0].message.content)

import OpenAI from "openai";

const client = new OpenAI({
  baseURL: "https://model.51a.online/v1",
  apiKey: "sk-你的密钥",
});

const resp = await client.chat.completions.create({
  model: "glm-5.2",
  messages: [{ role: "user", content: "你好" }],
});
console.log(resp.choices[0].message.content);

工具接入

通用配置

大多数工具只需要填三项。在工具的「设置 → 模型服务 / 提供商」里新增自定义服务，协议选 OpenAI 兼容（OpenAI Compatible）：

字段填写
API 地址 / Base URLhttps://model.51a.online/v1
API Key你创建的 sk-...
模型名称先用 glm-4.6 或 gpt-6-luna 测试

保存后新建对话，问一句"你好"，能收到回复就接好了。想换 GPT / GLM / DeepSeek，只在工具里切换模型名，地址和 Key 不变。

Cherry Studio

打开 设置 → 模型服务 → 添加提供商，选择 OpenAI 兼容，按上表填三项，保存后启用模型，在聊天窗口选择刚添加的模型即可。

VS Code（Cline / Roo Code 等）

提供商选 OpenAI Compatible，Base URL 填 https://model.51a.online/v1，API Key 填自己的 Key，模型名填 gpt-6-luna 或 glm-4.6。如果插件会自动拼 /v1，把地址改成 https://model.51a.online。

Claude Code

Claude Code 用 Anthropic 兼容协议，与其他工具不同：Base URL 不带 /v1。

export ANTHROPIC_BASE_URL=https://model.51a.online
export ANTHROPIC_AUTH_TOKEN=sk-你的密钥
export ANTHROPIC_MODEL=gpt-6-luna
claude

用 CC Switch 管理多个供应商的用户：在 CC Switch → Claude Code → 添加供应商 选「自定义」（不是 Anthropic 官方），API URL 填 https://model.51a.online，密钥填自己的 Key，并在高级设置里核对下面的模型映射——只填地址和 Key、不配四个模型映射，会出现 model_not_found：

模型映射示例值用途
ANTHROPIC_MODELgpt-6-luna主模型
ANTHROPIC_DEFAULT_SONNET_MODELgpt-6-lunaSonnet 档任务
ANTHROPIC_DEFAULT_OPUS_MODELgpt-6.1-terraOpus 档任务

如果你曾在终端设置过 ANTHROPIC_BASE_URL 等环境变量，旧值可能覆盖新配置；修改后完全退出并重新打开工具。

Codex CLI

Base URL 填 https://model.51a.online/v1，API Key 填自己的 Key，模型选 GPT 系列（复杂代码任务可从 gpt-6.1-terra 开始）。新版 Codex CLI 使用 /v1/responses 端点，如遇 reasoning.context 相关 400 报错，需要在配置中关闭 use_responses_lite——这不是 Key 无效，属于进阶配置，可参考 Codex 文档或联系我们协助。

GPT、GLM、DeepSeek 全系共用一套 Key、一套网关地址。完整模型清单与实时价格以控制台「模型广场」为准；个别渠道因上游额度暂时不可用时，网关会自动切换到其他可用渠道。

计费说明

  • 计价单位：按 token 用量计费，价格对齐各模型官方 API。
  • 缓存折扣：命中提示词缓存的输入按官方缓存价计费（约为输入价的 10%），长会话/Agent 场景成本大幅降低。
  • DeepSeek 分时：deepseek-flash 系列按峰谷计价——工作日 9-12 点、14-18 点为峰值价，其余时段（含夜间与周末）为峰值 8 折。
  • 充值汇率：按充值时页面展示的汇率结算，充值余额永不过期。
  • 账单透明：控制台「日志」可逐条核对每次请求的 token 数与费用。

常见问题

  • 支持流式输出吗？ 支持，所有文本模型均可 stream: true。
  • 一个密钥能换模型吗？ 能。密钥与模型无关，请求里改 model 字段即可。
  • 401 / Invalid token？ Key 复制不完整或已删除，回到控制台重新复制。
  • 404？ 地址路径不对。聊天工具用 /v1 结尾的地址，Claude Code 用不带 /v1 的根地址。
  • 503 model_not_found？ 模型名拼写与模型广场不一致（注意大小写与 [1M] 后缀）。
  • 报 429 怎么办？ 触发了使用限制（速率或套餐额度），稍后重试或升级套餐。
  • 数据安全？ 请求内容仅用于本次转发与计费统计，不用于训练。
